# Tuan Minh — Business Analyst Portfolio

Standalone portfolio source prepared from the Lovable prototype.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.

`vercel.json` includes an SPA rewrite so `/projects/recruitment-management` can be opened directly.
